### Example: kustomize

[![Open in Cloud Shell](https://gstatic.com/cloudssh/images/open-btn.svg)](https://ssh.cloud.google.com/cloudshell/editor?cloudshell_git_repo=https://github.com/lucky-tools/devloop&cloudshell_open_in_editor=README.md&cloudshell_workspace=examples/kustomize)

This is an example demonstrating: how devloop can work with kustomize with the `devloop deploy` command.

Can be run with:

```bash
devloop deploy -f devloop-kustomize-args.yaml
```
